# Farit's Research: Complete Evidence Retrieval under Reading Budgets

## Research Question
How to find the COMPLETE set of evidence for SDS fields under limited reading budgets?

## Structure
- `src/retrieval/` - Retrieval models (BM25, dense, etc.)
- `src/evaluation/` - Evidence-specific metrics
- `src/budget/` - Budget management
- `experiments/` - Experiment configurations
- `notebooks/` - Analysis notebooks
- `results/` - Output tables and figures

## Dependencies
See `requirements.txt` for additional requirements.

## Workflow
1. Use `notebooks/` for data exploration and analysis
2. Use `src/` for reusable modules
3. Use `experiments/` for specific experiment runs
4. Save results to `results/`
